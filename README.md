# Widi Store

Proyecto web desarrollado como práctica de **Programación III – UTN**.  
Incluye sistema de tema claro/oscuro, navegación con Bootstrap y estructura modular de carpetas.

## 📂 Estructura del proyecto
- **css/** → estilos (`estilos.css`)
- **js/** → lógica de tema (`theme.js`)
- **imagenes/** → recursos gráficos (logo `widiLogoRedondo.png`)
- **vistas/** → páginas HTML (`index.html`, `productos.html`, `carrito.html`.)

## ✨ Funcionalidades
- Header con navegación responsive usando **Bootstrap**.
- Botón de cambio de tema (claro/oscuro) con persistencia en `localStorage`.
- Footer fijo.

## 🚀 Cómo ejecutar
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/guadafestinese96/widistore-tp.git
Abrir vistas/index.html en el navegador.

2. Navegar entre las páginas y probar el botón de cambio de tema.

3. 🛠️ Tecnologías
- HTML5
- CSS3 + Bootstrap 5
- JavaScript (DOM + localStorage)
